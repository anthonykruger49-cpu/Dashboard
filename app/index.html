Publish & Run on Android via Termux

Your LTE RTU Gateway (e.g., USR-G806, Teltonika TRB245, or Waveshare RS485-to-LTE) bridges RS485 Modbus RTU from the 4 Megarevo MPS inverters and 4 Schneider PowerLogic meters over TCP/IP (VPN or Static IP). Run the Python poller + web server below inside Termux to serve this dashboard and expose /api/telemetry: 

# 1. Update Termux & install Python + pure-Python pymodbus (no Rust build needed)
pkg update -y && pkg upgrade -y
pkg install python -y
pip install pymodbus

# 2. Save this dashboard as index.html in ~/scada/
mkdir -p ~/scada && cd ~/scada

# 3. Create zero-dependency server.py (polls LTE Gateway TCP 502 & serves UI on port 8085)
cat << 'EOF' > ~/scada/server.py
import json, struct
from http.server import SimpleHTTPRequestHandler, ThreadingHTTPServer
from pymodbus.client import ModbusTcpClient

LTE_GATEWAY_IP = "10.8.0.12"  # Change to your LTE Gateway IP
LTE_GATEWAY_PORT = 502

class ReusableHTTPServer(ThreadingHTTPServer):
    allow_reuse_address = True

def read_float32(client, address, slave):
    res = client.read_holding_registers(address=address, count=2, slave=slave)
    if res.isError():
        return None
    raw = struct.pack(">HH", res.registers[0], res.registers[1])
    return round(struct.unpack(">f", raw)[0], 2)

def read_u16(client, address, slave, scale=1.0):
    res = client.read_holding_registers(address=address, count=1, slave=slave)
    if res.isError():
        return None
    return round(res.registers[0] * scale, 2)

def poll_gateway():
    client = ModbusTcpClient(LTE_GATEWAY_IP, port=LTE_GATEWAY_PORT, timeout=2)
    if not client.connect():
        return {"connected": False, "error": "LTE Gateway unreachable"}
    data = {"connected": True, "inverters": {}, "meters": {}}
    try:
        for inv_id in range(1, 5):
            data["inverters"][f"INV-{inv_id}"] = {
                "p_kw": read_u16(client, 0x3026, inv_id, 0.1),
                "q_kvar": read_u16(client, 0x3028, inv_id, 0.1),
                "bat_v": read_u16(client, 0x3010, inv_id, 0.1),
                "bat_soc": read_u16(client, 0x3013, inv_id, 1.0),
                "pv_kw": read_u16(client, 0x3008, inv_id, 0.1),
                "temp_c": read_u16(client, 0x3030, inv_id, 0.1),
            }
        for slave_id, name in {11: "T1", 12: "T2", 13: "G1", 14: "G2"}.items():
            data["meters"][name] = {
                "v_ll": read_float32(client, 3020, slave_id),
                "i_avg": read_float32(client, 3000, slave_id),
                "p_kw": read_float32(client, 3060, slave_id),
                "q_kvar": read_float32(client, 3068, slave_id),
                "s_kva": read_float32(client, 3076, slave_id),
                "pf": read_float32(client, 3084, slave_id),
                "freq": read_float32(client, 3110, slave_id),
                "kwh_imp": read_float32(client, 3204, slave_id),
            }
    finally:
        client.close()
    return data

class ScadaHandler(SimpleHTTPRequestHandler):
    def do_GET(self):
        if self.path == "/api/telemetry":
            payload = json.dumps(poll_gateway()).encode("utf-8")
            self.send_response(200)
            self.send_header("Content-Type", "application/json")
            self.send_header("Access-Control-Allow-Origin", "*")
            self.end_headers()
            self.wfile.write(payload)
        else:
            super().do_GET()

if __name__ == "__main__":
    pkill_note = "Run: pkill -f python  # if restarting"
    server = ReusableHTTPServer(("0.0.0.0", 8085), ScadaHandler)
    print("in4solar SCADA Dashboard live at http://0.0.0.0:8085")
    server.serve_forever()
EOF

# 4. Run on Port 8085 (Open http://localhost:8085 in your browser)
python ~/scada/server.py

RS485 Bus Topology & Modbus Register Map

RS485 Port A: Megarevo MPS
  • • Baud: 9600 bps, 8N1
  • • MPS Unit 1: Slave ID 0x01 (1)
  • • MPS Unit 2: Slave ID 0x02 (2)
  • • MPS Unit 3: Slave ID 0x03 (3)
  • • MPS Unit 4: Slave ID 0x04 (4)
RS485 Port B: Schneider PM
  • • Baud: 19200 bps, 8E1
  • • Transformer 1: Slave ID 11
  • • Transformer 2: Slave ID 12
  • • Generator 1: Slave ID 13
  • • Generator 2: Slave ID 14
Device Family Address Type Parameter & Scale
Megarevo MPS 0x3000 UINT16 Operating State (0=Standby, 1=OnGrid, 2=OffGrid, 3=Fault)
Megarevo MPS 0x3004–0x3009 UINT16 PV1 & PV2 Voltage (0.1V), Current (0.1A), Power (0.1kW)
Megarevo MPS 0x3010–0x3015 INT16 Battery V (0.1V), I (0.1A), P (0.1kW), SOC (1%), SOH (1%)
Megarevo MPS 0x3020–0x302F INT32 Inverter L1/L2/L3 V, I, Active P (kW), Reactive Q (kVAr), Hz
Schneider PM5xxx 3000–3010 FLOAT32 Currents I_L1, I_L2, I_L3, I_N, I_Avg (Amps)
Schneider PM5xxx 3020–3036 FLOAT32 Voltages V_L12, V_L23, V_L31, V_L1N, V_L2N, V_L3N (Volts)
Schneider PM5xxx 3054–3084 FLOAT32 Active P (kW), Reactive Q (kVAr), Apparent S (kVA), PF Total
